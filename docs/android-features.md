# 泥工小窝安卓端功能表

安卓端是 Expo / React Native 应用，包名 `com.nigo.nest`，当前版本 `1.0.4`。界面在 `mobile/src/screens`，接口封装在 `mobile/src/lib`。登录后底部只有两个标签：首页（广场）和我的。其余功能从「我的」进入。

生产接口基址是 `http://124.222.97.3:8788`，请求头带 `x-auth-token`。热更新清单走 `https://njtech.linfk.com/api/ota/manifest`，安卓运行时版本固定为 `1.0.4`，所以界面改动可以热更新，不必重装。

总控可以用 `GET /api/app/features` 开关部分入口。开关关掉后，「我的」里对应一行不出现。

## 功能一览

| 功能 | 入口 | 主要接口 | 怎么实现 |
| --- | --- | --- | --- |
| 登录 | 启动未登录时 | `POST /api/auth/login` | 学工号和密码交给服务端。服务端走学校统一认证的 HTTP 接口，不在手机上打开登录网页。成功后保存令牌，并记住账号以便下次填入。 |
| 热更新 | 正式包启动时 | `GET /api/ota/status`，再拉 Expo 清单 | `expo-updates` 只在正式 APK 里启用。开发包跳过。安卓和 iOS 的清单分开存，发一边不会冲掉另一边。 |
| 广场 | 底栏「首页」 | `GET /api/posts` | 分页拉帖子。点头像进同学资料。 |
| 发帖 | 广场 | `POST /api/posts` | 弹层写内容，带当前令牌提交。 |
| 点赞、评论、回复 | 帖子卡片 | `POST /api/posts/:id/like`，`GET/POST /api/posts/:id/comments` | 评论可回复某一条。赞和评论数写回当前列表。 |
| 我的动态 | 我的 → 广场 | `GET /api/me/posts`，`GET /api/me/comments` | 列出自己的帖和评论，可删除。 |
| 同学资料 | 点头像 | `GET /api/users/:id/profile` | 看昵称、头像、年级和好友状态，再决定加好友或发消息。 |
| 好友 | 我的 → 好友 | `GET /api/friends`，申请、同意、拒绝、删除 | 列表带最后一条消息和未读数。收到的申请可在好友页和单独的申请页处理。 |
| 聊天 | 好友列表 | `GET/POST /api/friends/:id/messages` | 按学号拉消息、发文本。左右气泡区分自己和对方。 |
| 消息通知 | 我的 → 消息通知 | `GET /api/notifications`，未读数，单条已读，全部已读 | 类型包括点赞、评论、好友、抢课、考试和建议回复。好友类通知可跳到好友页。未读数显示在「我的」角标上。 |
| 账号资料 | 点头像卡片 | `GET /api/user/me`，`POST /api/user/nickname`，`POST /api/user/avatar` | 改昵称有长度限制。头像用图片的 base64 JSON 上传，避免安卓上分片上传不稳定。可佩戴称号。 |
| 每日签到 | 「我的」顶部卡片 | `GET/POST /api/checkin` | 每天一次。积分和连续天数由服务端计算，客户端只展示并提交签到。 |
| 积分排行榜 | 签到卡片底部 | `GET /api/checkin/leaderboard` | 展示名次、昵称、积分，并标出自己。 |
| 课表 | 我的 → 教务 | `POST /api/schedule/terms`，`POST /api/schedule/import` | 学期列表以教务返回为准。导入后按周课表画格子，本地缓存课表。 |
| 课表备注 | 点开一节课 | `GET/POST /api/schedule/notes` | 备注挂在「课程 + 星期 + 节次」上。空文本表示清除。保存后刷新桌面小组件。 |
| 桌面小组件 | 系统桌面 | 本地课表和备注，不单独请求 | 安卓用 `react-native-android-widget` 画「下一节课」。可选简洁卡片或深色表格。导入课表、改备注、回到前台时主动刷新。 |
| 空教室 | 我的 → 教务 | `GET /api/classroom/meta`，`POST /api/classroom/empty` | 先拉校区、楼栋，再按周次、星期、节次查询。教务会话失效时提示重新登录。 |
| 场馆预约 | 我的 → 教务 | `GET /api/venue/catalog`，`GET /api/venue/slots`，`POST /api/venue/book` | 校区、场馆、场地、日期都是点选。可约时段直接提交，不手填编号。人数不够时不能提交。 |
| 预约记录和支付 | 场馆页 | `GET /api/venue/orders`，`POST /api/venue/pay` | 「去支付」打开学校支付页。金额为 0 也保留支付入口。App 不代收付款。 |
| 同伴 | 场馆页，也可单独打开 | `GET/POST /api/venue/buddies`，`POST /api/venue/buddies/remove` | 添加、删除预约同伴，预约时勾选。 |
| 自动抢课 | 我的 → 辅助，可被总控关闭 | `GET /api/course-grab/courses`，任务的创建、列表、日志、取消、重新授权 | 搜索课程后加入愿望单，可限定星期和节次。创建任务时提交一次教务密码和开始时间，由服务端到点执行。状态和日志在任务卡片里看。 |
| 迎新答题 | 仅学号以 2026 开头，且总控开启 | `GET /api/yx-exam/papers`，预览、安排、任务、取消 | 先预览预计分数和未匹配题，再指定交卷时间。任务列表可取消最近一条。 |
| 安全知识考试 | 同样只对 2026 级，且总控开启 | `GET /api/bwcks/captcha`，`POST /api/bwcks/login`，科目、开考、任务、取消 | 用考试系统账号登录后选科目。开考和交卷由服务端按学校规则执行，手机只负责登录、选题和查看任务。 |
| 功能建议 | 我的 → 建议，单独一组 | `GET/POST /api/suggestions` | 用户提交文字。管理员在总控采纳或拒绝并回复，回复出现在用户自己的列表里，并可以通知到消息。 |
| 分享 | 「我的」右上角 | `GET /api/app/version` | 读取总控配置的安装包地址，调起系统分享。没有下载地址就提示尚未配置。 |
| 创高体育自动跑步 | 仅当总控把 `chuanggaoRun` 打开 | 无 | 只显示「即将上线」，没有跑步、定位或打卡实现。 |

## 和发布相关的约定

- 安卓界面更新走热更新，运行时版本保持 `1.0.4`。
- 原生能力不能热更新。桌面小组件、新的系统权限，都要发新的安装包。
- 登录、验证码和取用户信息都走 HTTP 接口。不使用浏览器自动填表登录。
- 抢课和考试使用学生自己的学校账号，密码只在当次请求里交给服务端，不写进仓库。
